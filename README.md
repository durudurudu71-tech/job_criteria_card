# 직업기준카드 웹앱 V0.6

직업상담자와 내담자가 핵심기준, 현실검증, WDEP 실행계획을 정리하고 한 화면의 1회기 최종 결과로 확인하는 브라우저용 웹앱입니다.

내담자에게 앱의 목적, 진행 순서, 결과 해석과 개인정보 저장 방식을 안내할 때는 `내담자_사용안내.md`를 사용합니다.

현재 구현된 화면과 기능을 검토하고 수정보완 방향을 논의할 때는 `V0.6_현행_웹화면_기능명세.md`를 사용합니다.

실제 화면에 보이는 문구와 버튼만 순서대로 검토할 때는 `V0.6_실행화면_검토목록.md`를 사용합니다.

## 실행 방법

별도 설치 없이 `index.html`을 더블클릭해 브라우저에서 엽니다. 인터넷 연결이나 서버가 필요하지 않습니다.

## 데이터와 저장

- 카드 원본: `직업기준카드.md`
- 앱 데이터: `data/cards.js` (B05는 개발 지시서의 최종 수정안 적용)
- 상담질문·참고 태그·기준출처: `data/counseling.js`
- 현실검증 기준·카드조합 규칙: `data/settings.js`
- 상담 진행상황: 브라우저 LocalStorage

브라우저별로 데이터가 따로 저장됩니다. 결과 화면의 **새 상담 시작** 버튼으로 현재 상담 데이터를 초기화할 수 있습니다.
